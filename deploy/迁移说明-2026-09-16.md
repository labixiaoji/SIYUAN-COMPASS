# 89 服务器反代迁移

本说明取代旧部署记录中关于公网 Nginx 和内部静态站的拓扑说明。
学校将 https://ai4edu.sjtu.edu.cn/shengya/ 转发到 http://10.119.9.89/，并剥掉 /shengya 前缀。

- 使用 nginx-siyuan-compass-origin.conf 替换 89 的 /etc/nginx/conf.d/siyuan-compass.conf，禁用默认欢迎页。不再使用旧 public/static 模板。
- 前端直接读取 /opt/SIYUAN-COMPASS/frontend/dist，不再需要 18121 静态代理。
- /api/ 原样转发到 127.0.0.1:18120，保留学校传来的 HTTPS 协议信息。
- 前端构建保持 VITE_BASE_PATH=/shengya/、VITE_API_BASE_URL=/shengya/api、VITE_ENABLE_LOCAL_AUTH=false。
- 后端保持 PUBLIC_APP_URL=https://ai4edu.sjtu.edu.cn、APP_BASE_PATH=/shengya、FRONTEND_ORIGINS=https://ai4edu.sjtu.edu.cn、LOCAL_AUTH_ENABLED=false。
- jAccount 回调保持 https://ai4edu.sjtu.edu.cn/shengya/api/auth/jaccount/callback，登出回跳保持 https://ai4edu.sjtu.edu.cn/shengya/。
- 现场 systemd 使用 /opt/SIYUAN-COMPASS/backend 和 /opt/siyuan-compass-sjtu-venv/bin/uvicorn；不要直接用旧模板覆盖现场服务。
- 数据库此前映射到 127.0.0.1:5433，连接信息以服务器实际配置为准。切换代理不等于迁移旧站数据库。
- 学校外层代理超时为 120 秒；内层的 300 秒不会扩大该限制。

应用前备份 Nginx 配置和默认站点，修改后先 nginx -t 再 reload。
验收公网首页、/shengya/assessment、首页引用的 JS/CSS、jAccount 跳转、本地登录禁用和管理 API 鉴权。
登录授权回调需使用真实 jAccount 在浏览器完成验证。

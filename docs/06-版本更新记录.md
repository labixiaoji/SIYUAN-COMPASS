# 版本更新记录

每次有重要功能更新时追加一条记录，只写日期、标题和更新内容。

## 2026-09-07｜增加模型请求 RPM 限制

新增进程级平滑 RPM 限流，画像、报告、质量修复和重试请求共用模型请求速率；同步开发与部署 Compose 配置、环境变量模板、文档和测试。

## 2026-09-03｜压缩模型提示词输入

画像只发送有答案的题目规则，报告以结构化画像为主并仅补充困惑、基本信息和5—10年愿景，删除重复说明和格式化空字段，减少单次模型输入消耗并保持原有字段、章节和隐私边界。

## 2026-09-03｜收敛管理员报告工作台

合并填写记录与生成过程展示，移除独立生成任务列表；已生成报告改为卡片布局；审计日志只保留报告修改和删除记录，不再记录管理员查看操作。

## 2026-09-03｜恢复管理员宽版报告卡片

恢复学生、问卷、报告状态和反馈的宽版卡片展示，增加姓名、学院、专业模糊搜索以及报告状态和年级筛选。

## 2026-09-01｜开放模型输出上限配置

新增 `LLM_MAX_OUTPUT_TOKENS` 环境变量，统一控制画像和报告请求的单次输出上限，并补充配置文档与测试。

## 2026-08-31｜移除语音转写功能

删除前端录音入口、后端转写接口、讯飞适配器、相关配置、配额字段和测试，系统改为仅支持文本填写。

## 2026-08-29｜增加报告排队与模型并发控制

报告生成改为 PostgreSQL 持久任务队列和固定 3 个 Worker；统一模型接口限制并发、支持超时重试和统计，补充断点恢复、完整性校验、行动项格式兼容、管理员排队统计和相关测试文档。

## 2026-08-28｜完善管理员任务查看与失败问卷恢复

拆分管理员总览、填写记录、生成任务、成功报告和审计日志页面；增加失败任务错误代码与定位信息，保留失败问卷快照并支持恢复生成。

## 2026-08-18｜调整账户配额默认值

报告生成默认配额改为 0，表示不限制；部署时可在 .env 中设置正数启用每日配额。

## 2026-08-18｜完善移动端规范适配

调整手机端导航、规范色值、字体、按钮触控尺寸和窄屏布局处理。

## 2026-08-17｜整理项目文档

重新生成问卷规范、系统实现、部署运维、数据隐私、开发测试和版本更新文档，删除旧方案和原始资料文档。

## 2026-08-14｜优化后端依赖安装

为后端 Docker 构建增加镜像源、下载超时和重试配置，降低部署时 Python 依赖下载失败的概率。

## 2026-08-14｜增加云端问卷草稿

增加按账号隔离的云端草稿，支持自动保存、恢复、版本冲突提示和提交后自动清除，并保留本地草稿作为网络异常兜底。

## 2026-08-05｜调整问卷字段和隐私处理

姓名、学号和联系方式改为选填，性别及未来收入预期按问卷规则处理，并限制身份信息进入大模型。

## 2026-07-30｜适配交我办网页端配色

调整网页端颜色、按钮和页面状态样式。

## 2026-07-16｜区分开发与生产 Docker 配置

增加本地开发 Compose 和服务器生产 Compose，分别支持热更新和 Nginx 部署。

## 2026-07-16｜完善报告生成体验

支持 Kimi 和 DeepSeek 两个模型通道，完善报告生成阶段、质量检查和失败处理。

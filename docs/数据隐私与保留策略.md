# 思源 Compass 数据隐私与保留策略

版本：1.0
适用范围：学生端、管理员端、后端数据库、浏览器草稿以及大模型调用链路。

## 1. 基本原则

1. 只为身份认证、生成生涯报告、向本人展示历史结果和必要的安全审计处理数据。
2. 姓名、学号和联系方式在问卷中均为选填；统一认证仍由学校侧负责，问卷字段只用于必要的归属、管理或联系。
3. 身份信息与生涯分析内容分开处理；姓名、学号、联系方式、收入预期、内部 ID 和时间戳不得发送给大模型。自由文本在发送前按可识别范围脱敏。
4. 大模型原始输出只在当前请求内用于解析和校验，不写入长期画像记录；长期保存的是通过结构校验后的画像和最终报告。
5. 学生可以删除自己的数据。达到保存期限的数据由系统自动清理，不依赖人工逐条操作。

## 2. 字段处理清单

表中的“长期”指账号正常使用期间保存；用户清除全部业务数据或删除相应报告后，相关在线数据应立即不可访问，并在 30 天内从延迟删除介质或备份中清除。

| 数据类别 | 具体字段或数据 | 是否采集 | 是否传给模型 | 保存方式 |
| --- | --- | --- | --- | --- |
| 账号与权限 | 学校统一认证提供的账号标识（接入后）、内部 `users.id`、展示名、角色 | 是 | 否 | 长期；仅用于登录、归属和权限判断；本轮未改造认证方式 |
| 每日生成配额 | 当前自然日、已创建任务次数 | 系统计数 | 否 | 短期；清除业务数据后仍随登录账号保留到当日结束，避免通过删除绕过配额；次日启动或每日清理时清零 |
| 语音录音 | 用户主动点击语音输入后产生的浏览器音频 | 是；仅发送至配置的转写供应商 | 否 | 仅在一次转写请求期间保存在服务内存中；不写入数据库、不进入报告；请求结束后释放。启用讯飞时，音频会进入讯飞录音文件转写订单，需按学校审批确认供应商侧处理期限 |
| 语音转写文本 | 供应商返回的文字 | 是；用户确认后进入对应问卷字段 | 按该问卷字段规则脱敏后发送 | 随问卷字段按现有问卷保留规则保存；未提交的文字只停留在当前浏览器草稿 |
| 每日语音转写配额 | 当前自然日、转写尝试次数 | 系统计数 | 否 | 短期；清除业务数据后仍随登录账号保留到当日结束，次日启动或每日清理时清零 |
| 问卷身份字段 | `studentName`、`studentNumber`（旧版 `school` 仅兼容存量数据） | 是；姓名、学号选填，用于问卷归属和必要后台管理 | 否 | 随问卷长期保存；学生删除问卷或全部业务数据时删除 |
| 联系方式 | `contactInfo` | 是；选填，仅用于学生主动提供后的必要联系 | 否 | 随问卷长期保存；学生删除问卷或全部业务数据时删除 |
| 性别 | `gender` | 是；必填，可选择“不便透露”，用于完善生涯路径分析 | 是 | 长期、限制访问；学生删除问卷或全部业务数据时删除 |
| 教育背景 | `educationStage`、`grade`、`collegeMajor`、`hometown` | 是 | 是 | 长期；其中家乡仅用于目标城市迁移与支持条件分析 |
| 教育路径 | `mastersIntention`、`mastersPlan`、`phdIntention`、`phdPlan`、`doctoralCareerDirection`、`doctoralCareerOther`、`educationPathReasons`、`educationPathReasonOther` | 是 | 是；无关的“其他”补充字段不发送 | 长期 |
| 已停用问卷项 | `educationCertainty`、`englishCertificates`、`academicExperiences`、`executionCase`、`negativeFeedbackReaction` | 否 | 否 | 不保存；存量数据应一次性清理 |
| 收入目标 | `fiveYearIncome`、`tenYearIncome` | 是；5 年和 10 年预期收入均为必填 | 否 | 长期、限制访问；仅作问卷记录，不判断收入目标是否现实或购房能力 |
| 5—10 年愿景 | `fiveYearCity`、`fiveYearIndustry`、`fiveYearRole`、`fiveYearFamilyStatus`、`fiveYearHousingPlan`、`fiveYearHobbiesSkills`、`tenYearCity`、`tenYearIndustry`、`tenYearRole`、`tenYearFamilyStatus`、`tenYearHousingPlan`、`tenYearHobbiesSkills` | 是 | 是 | 长期；报告只保留与生涯路径有关的必要概括 |
| 价值、能力与兴趣 | `topValuesRanked`、`abilityScores`、`interestScores` | 是 | 是 | 长期；能力自评不得当作已验证能力 |
| 学业竞争力 | `currentGpa`、`gpaScale`、`majorRank`、`majorTotal`、`failedCourseStatus` | 是 | 是 | 长期、限制访问；只用于教育路径可行性分析 |
| 第二专业与转专业 | `hasSecondMajor`、`secondMajorName`、`secondMajorProgress`、`secondMajorCareerInterest`、`hasTransferredMajor`、`originalMajorName`、`transferReason`、`originalMajorRetainedSkills` | 是 | 是 | 长期 |
| 优势与兴趣证据 | `praisedTraits`、`traitEvidence`、`immersiveActivities`、`favoriteKnowledgeAreas`、`selfDrivenActivities`、`preferredWorkStyle` | 是 | 是 | 长期 |
| 行动与资源 | `currentPreparations`、`currentPreparationOther`、`preparationDetails`、`missingResources` | 是 | 是；无关的“其他”补充字段不发送 | 长期 |
| 职业信息能力 | `majorOutcomeAwareness`、`targetJobAwareness`、`jobInfoChannels`、`jobInfoChannelOther` | 是 | 是；无关的“其他”补充字段不发送 | 长期 |
| 健康与心理感受 | `healthEnergyStatus`、`exerciseFrequency`、`failureRecoveryTime`、`selfDoubtFrequency`、`supportNeed` | 是 | 是 | 长期、限制访问；只用于节奏和支持建议，不用于诊断；题目前不增加额外用途说明 |
| 执行与风险偏好 | `longTermPersistence`、`executionStyle`、`problemSolvingStyle`、`highIntensityExperience`、`routineWorkTolerance`、`careerRiskPreference` | 是 | 是 | 长期 |
| 生涯困惑 | `careerConfusions`、`careerConfusionOther`、`mainConfusionText` | 是 | 是；无关的“其他”补充字段不发送 | 长期 |
| 内部关联元数据 | 问卷、画像和报告的 `id`、`userId`、`responseId`、`profileId`、`createdAt`、`submittedAt`、`updatedAt` | 系统生成 | 否 | 随对应业务记录长期保存，不得出现在模型请求中 |
| 结构化画像 | 画像摘要、证据、反证、风险、信息缺口、Plan A/B/C、质量警告、模型名和提示词版本 | 系统生成 | 报告阶段仅发送必要的结构化字段 | 长期 |
| 大模型原始输出 | `rawModelOutput` 及报告生成中间稿 | 请求期间临时产生 | 不适用 | 不保存；解析或质量校验完成后即释放 |
| 最终报告与版本 | 报告标题、正文、质量状态、模型和提示词版本、人工编辑版本 | 系统生成 | 否；修改问卷后生成新报告时重新使用脱敏输入 | 长期，直至学生删除 |
| 报告反馈 | 各项评分和可选文字反馈 | 学生主动提交 | 否 | 长期，直至学生删除；统计时优先使用去标识数据 |

自由文本可能被学生重复填入姓名、学号或联系方式。模型请求构造阶段会再次替换问卷身份字段中的已知值，并识别明显的邮箱、手机号和 8—20 位长数字标识；姓名、地址、社交账号等内容无法在不大量误删正常回答的前提下可靠识别，因此仍应避免在自由文本中填写不必要的身份信息。

## 3. 短期数据和自动清理期限

| 数据 | 起算时间 | 最长保存时间 | 到期处理 |
| --- | --- | --- | --- |
| 浏览器问卷草稿 | 最后一次保存草稿 | 7 天 | 到期后不可读取，并在下次打开系统时扫描清理；退出或切换账号时清除当前设备上的上一账号草稿 |
| 生成任务记录 | 任务进入 `success`、`failed` 或 `cancelled` | 30 天 | 删除任务状态、错误详情和临时输入；正式问卷、画像和报告按各自规则处理 |
| 管理员审计日志 | 管理操作发生 | 180 天 | 自动删除；导出的审计副本也不得超过同一期限 |
| 经同意收集的回访联系方式 | 收集成功 | 30 天 | 回访完成即删除，最长不超过 30 天 |
| 模型请求与原始响应 | 单次模型请求开始 | 请求处理期间 | 结构化解析和质量校验完成后释放，不进入数据库、日志或异常详情 |

清理任务至少每天运行一次，并记录“清理类型、清理数量、执行时间和结果”；清理日志不得反向记录被删除的问卷内容或联系方式。

## 4. 大模型数据边界

画像阶段和报告阶段共用同一份禁止字段清单：

- 直接身份：`studentName`、`school`、`studentNumber`、`contactInfo`；
- 内部元数据：`id`、`userId`、`submittedAt`、`createdAt`；
- 无需分析：`fiveYearIncome`、`tenYearIncome`、`educationCertainty`、`englishCertificates`、`academicExperiences`、`executionCase`、`negativeFeedbackReaction`。

除从结构上删除以上字段外，系统还会在最终请求文本中替换已知的姓名、学号、联系方式、学校、内部 ID 和时间戳，并替换明显的邮箱、手机号和长数字标识，降低学生在其他自由文本答案中重复填写这些值造成的泄露风险。自动识别不覆盖所有姓名、地址或社交账号，前端提示仍是必要的第一道边界。

生产上线前，学校还需要与所选模型服务商确认并留档：数据处理地域、传输加密、服务端日志期限、是否用于训练、子处理方、泄露通报机制和删除承诺。若无法满足学校要求，不得发送真实学生问卷。

当前讯飞录音文件转写大模型接口为异步订单模式，查询结果会返回供应商侧的订单过期信息。该期限属于供应商侧结果保留，不等同于本系统保存；上线前应以控制台开通产品对应的服务协议和实际返回的过期时间为准，并由学校确认是否满足数据合规要求。

## 5. 删除与访问规则

1. 学生只能访问和删除自己的问卷、画像、报告、报告版本及反馈。
2. 删除单份报告时，应同时删除其画像、问卷和反馈；如果同一问卷确实被多个报告引用，需在界面提示关联范围后再执行。
3. 清除全部业务数据时，应停止该账号的运行中任务，并级联删除问卷、画像、报告、版本、反馈和生成任务；登录账号本身保留。管理员审计日志保留到 180 天，但其中只保留最小操作信息。
4. 管理员查看敏感问卷必须基于工作需要；查看、编辑、导出和删除均写入审计日志。
5. 日志、错误消息和监控指标不得记录完整问卷、模型请求、模型响应、Token、联系方式或数据库连接密钥。
6. 数据导出默认脱敏，不批量输出联系方式、健康心理感受或完整自由文本；确需导出须明确目的、范围和销毁时间。

## 6. 本轮实现状态与上线前检查

已实现：

- 画像和报告两阶段统一排除直接身份、内部元数据及不需要分析的字段；
- 对自由文本和旧画像中重复出现的已知身份值、明显邮箱、手机号及长数字标识进行二次替换；
- 结构化画像在校验和保存前再次脱敏，管理员编辑报告时也会阻止保存明显的联系方式或长数字标识；
- 新生成画像不再写入 `rawModelOutput`；
- 前端采集姓名、学号和联系方式（选填），性别及 5/10 年预期收入（必填）；旧报告预填会恢复已有字段；
- 正式问卷和可恢复任务输入保留本轮采集字段，但不保存已停用字段，并每日清理存量已停用字段与原始模型输出；
- 浏览器草稿按用户隔离、最长保留 7 天，退出时清理；
- 生成任务终态输入立即清空、记录保留 30 天，管理员审计日志保留 180 天；
- 每日生成配额计数不随业务数据删除而重置，并在对应自然日结束后由维护任务清零；
- 学生可删除单份报告关联数据，也可清除全部业务数据但保留登录账号；
- 管理员查看指标、学生记录、完整问卷、报告以及执行修改、删除时写入审计；
- 自动化测试覆盖模型请求脱敏、原始输出不落库、删除并发保护、保留期清理和管理员审计。

上线前仍需由学校或部署方落实：

- 完成学校统一认证对接；本轮没有修改登录方式；
- 明确备份介质的延迟删除流程，并验证 30 天内完成清除；
- 完成模型供应商数据处理评估后再使用真实学生数据联调。

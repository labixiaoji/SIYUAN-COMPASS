# 数据隐私与保留策略

本文档是系统数据处理的当前依据。真实上线前还需要由学校确认统一认证和模型供应商的合规条款。

## 1. 数据处理原则

1. 只收集问卷、报告生成、本人查看和必要审计所需的数据。
2. 姓名、学号和联系方式是选填信息。
3. 不把不必要的身份信息和内部关联信息发送给大模型。
4. 大模型原始输出只在当前请求中解析和校验，不写入长期记录。
5. 学生可以删除自己的业务数据，过期数据由维护任务清理。

## 2. 字段边界

| 数据 | 是否采集 | 是否发送给模型 | 主要保存方式 |
| --- | --- | --- | --- |
| 姓名、学号、联系方式 | 是，选填 | 否 | 随问卷保存，删除问卷或全部业务数据时删除 |
| 性别、学历、专业、年级、家乡 | 是 | 性别和分析所需教育信息会发送 | 问卷和画像 |
| 5 年、10 年收入预期 | 是，必填 | 否 | 受限访问的问卷记录 |
| 教育路径、愿景、能力、兴趣、行动和困惑 | 是 | 按题目规则脱敏后发送 | 问卷、画像和报告 |
| 健康、精力和心理感受 | 是 | 发送，用于节奏和支持建议，不用于诊断 | 受限访问的问卷和画像 |
| 云端问卷草稿 | 是 | 否 | PostgreSQL，按账号隔离 |
| 浏览器本地草稿 | 可能存在 | 否 | 当前设备本地存储 |
| 原始模型响应 | 请求期间产生 | 不适用 | 不保存 |

学校字段仅为旧数据兼容字段，当前页面不主动采集。自由文本仍可能包含学生主动重复填写的身份信息，系统会替换已知值、邮箱、手机号和明显长数字标识，但无法可靠识别所有姓名、地址和社交账号。

## 3. 不保存和不发送清单

### 3.1 当前不保存的停用字段

- educationCertainty
- englishCertificates
- academicExperiences
- executionCase
- negativeFeedbackReaction

启动维护任务会清理历史记录中的这些字段。

### 3.2 不发送给大模型的字段

- studentName
- school
- studentNumber
- contactInfo
- id、userId、submittedAt、createdAt
- fiveYearIncome、tenYearIncome
- educationCertainty、englishCertificates、academicExperiences、executionCase、negativeFeedbackReaction

## 4. 保存期限

| 数据 | 默认期限 |
| --- | --- |
| 云端问卷草稿 | 最后保存后 30 天；生成失败或取消时保留，生成成功后删除对应任务草稿 |
| 浏览器本地草稿 | 7 天，退出或切换账号时清理当前账号数据 |
| 终态生成任务及失败恢复快照 | 30 天 |
| 管理员审计日志 | 180 天 |
| 生成配额计数 | 默认不限制；启用配额后保存到当日结束，次日清零 |
| 画像、报告、反馈 | 持续保存，直到学生删除或清除全部业务数据 |

系统启动时清理一次，运行期间每 24 小时清理一次。清理日志只记录类型、数量、时间和结果，不记录问卷内容。

## 5. 账户配额与计数

账户配额是按账号、按自然日计算的报告生成次数限制，用于控制模型服务的使用量。

当前默认值为 0，表示不限制：

~~~text
REPORT_GENERATION_DAILY_LIMIT=0
~~~

部署方可以在根目录 .env 中改成正数，例如：

~~~text
REPORT_GENERATION_DAILY_LIMIT=3
~~~

报告配额在创建生成任务时计数。成功、失败或取消不会自动返还已占用的次数；删除业务数据也不会重置当天计数。配额按配置的时区计算，默认时区为 Asia/Shanghai，跨自然日后自动清零。

## 6. 删除与访问

- 学生只能访问、删除自己的任务、问卷、画像、报告、版本和反馈。
- 删除单份报告时，清理不再被其他报告引用的关联数据。
- 清除全部业务数据时删除问卷、画像、报告、版本、反馈、任务和云端草稿，但保留登录账号。
- 失败任务的脱敏问卷快照仅保留到任务成功清理或终态任务超过 30 天；学生可在保留期内恢复后重新提交。
- 任务失败信息只保存脱敏的错误代码、阶段、摘要、供应商状态码和追踪编号，不保存完整堆栈、模型请求或响应。
- 生成任务还保存最小化的排队状态、Worker 尝试次数、模型请求/网络重试/质量修复次数，用于恢复和运维统计，不保存完整请求或响应。
- 删除业务数据不会重置当日报告生成配额。
- 管理员编辑或删除报告时写入最小化审计信息；查看问卷、学生记录、报告和修改记录不会产生新的审计事件。
- 日志、错误消息和监控指标不得记录完整问卷、模型请求、模型响应、密钥或联系方式。

## 7. 外部供应商

模型供应商可能产生供应商侧日志或调用记录。启用真实学生数据前，学校需要确认数据地域、传输加密、日志和调用记录保留期限、是否用于训练、子处理方和删除机制。
